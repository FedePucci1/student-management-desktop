# Origen del proyecto

La versión inicial fue creada por Federico Pucci como trabajo académico de Programación en NetBeans 8.2. Estaba dividida en los proyectos `Persona`, `DAO`, `PruebaDAO`, `Prueba DB` y `TestGUI`.

El sistema original ya contenía los conceptos centrales que conserva esta edición:

- Modelo orientado a objetos para personas y alumnos.
- Patrón DAO.
- Persistencia alternativa en archivos de texto y MySQL/MariaDB.
- Interfaz Swing con formularios generados por NetBeans.
- CRUD, búsqueda, filtros y baja lógica.

Los instaladores, binarios, rutas privadas del IDE y conectores JAR antiguos no forman parte del repositorio modernizado. El material original se conserva fuera de este repositorio dentro del archivo académico personal.
